Put the 3D car here as:  urus.glb

- Format: .glb (binary glTF). Keep it small (under ~8 MB) so the login page loads fast.
- Current model: "2019 Lamborghini Urus" by Ddiaz Design (Sketchfab), CC BY-NC-SA 4.0 -
  non-commercial use only, credited on /about. Changes to it (repaint, hidden badges) stay under the same licence.
- If the file is missing, the login page shows the SVG drawing instead.
- Orientation, paint colour and light positions are tuned at the top of
  frontend/src/auth/UrusScene3D.jsx (MODEL_TURN, PAINT_MATCH, HEADLIGHT, ...).
